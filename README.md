# myrepo

A starter repository for learning and using GitHub.

## What's here

- `README.md` – this file, describing the project.

## Getting started

```bash
git clone https://github.com/fahadashrafsumar/myrepo
cd myrepo
```

## Workflow

1. Create a branch: `git checkout -b my-feature`
2. Make changes and commit: `git add . && git commit -m "Describe change"`
3. Push: `git push -u origin my-feature`
4. Open a pull request on GitHub.
