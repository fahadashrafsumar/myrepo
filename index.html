Proof of concept

Private AI Server

To keep AI use inside the organisation's network for data-privacy reasons, I designed and deployed a self-hosted LLM platform in a sandboxed environment. It runs Ollama in a Docker container on Ubuntu Linux, with Open WebUI as the front end and Gemma 4 as the model.

The CPU-only prototype (Intel Xeon Gold) showed that a private AI assistant can run entirely in-house. Testing of response times and retrieval-augmented generation (RAG) made clear that GPU acceleration is needed before production. I used these findings to build a business case for a phased AI roadmap, starting with an NVIDIA RTX 5090 (32 GB) for the next testing phase.
